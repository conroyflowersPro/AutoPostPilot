# AutoPostPilot

Specialized content management PWA for @Seung4680.

## Features (MVP)

- Login with Supabase Auth
- Post list with scheduled times
- Specialized Grok review (X algorithm scoring)
- Media upload from phone
- Fedica scheduling integration
- xAI tools for media editing when needed

## Tech Stack

- Next.js 15 (App Router)
- Supabase (Auth + DB + Storage)
- Tailwind CSS
- Netlify deployment
- xAI Grok API
- Fedica Publishing API

## Setup

1. Clone the repo
2. Copy `.env.example` to `.env.local` and fill in keys
3. `npm install`
4. `npm run dev`

See `.env.example`
